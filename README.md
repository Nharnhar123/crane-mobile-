# Mobile Crane Services

A premium landing page for a mobile crane services business in Madina, Ghana. Built with React, Vite, Tailwind CSS, and Framer Motion.

Live demo: https://crane-mobile.vercel.app/

## Features
- Responsive industrial-themed landing page
- Strong hero section with animated visual effects
- Services, about, gallery, and contact sections
- WhatsApp enquiry CTAs
- Premium dark navy and safety-yellow branding
- Mobile-friendly navigation and layout

## Tech Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
